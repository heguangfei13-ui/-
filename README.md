# 置业罗盘｜杭州 / 南京商品房监测

面向 2027 年购房决策的公开匿名看板。正常运行时页面读取 D1 持久化快照，不在访问时采集外部网站；无可读数据库时会退回随源码保存的初始快照。任何登录、验证码或访问限制都不会被绕过。

## 当前完成度与限制

决策模型已升级至v2，差异、公式、置信度和数据准入规则见 [MODEL_V2.md](./MODEL_V2.md)。新看板独立展示城市基本面、市场时机、板块与资产分；缺失指标不填0/50，而是按有效证据归一化，并降低置信度。完全无证据的轴仍为空，其他轴不受阻。

- 每日北京时间 09:15 运行采集、校验、写入与 Git 归档；月度来源目前仍为固定发布页，自动发现下一期发布页尚未完成，不应把“页面请求成功”视为“最新一期已获取”。
- 已实现南京首页成交、LPR 和国家统计局两市总体新房/二手房价格表解析。70 城历史回填未完成，当前只有已解析月份；库存与成交历史缺口保持空值。
- 删除旧版示意序列与静态时机分数。v2仅从已保存证据确定性计分；低置信度不输出买入评级。
- 高德路线与 POI 已接入，项目定位需满足细粒度级别；仍可能需要官方地址交叉验证，未核验项目出入口。通勤为查询时估计，非工作日早高峰保证；轨道 POI 未核验运营状态。
- 杭州透明售房网公开入口返回 405，保留过期状态；不绕过访问限制。
- 楼盘价格、目标面积、交付风险证据尚未齐全，暂无可发布的推荐排名。土地、人口、就业、政策和长期历史仍待完成。
- 已增加杭州官方署名公报、南京统计局经济运行和南京卫健委人口数据解析；更多年龄/学历/就业子项不以现有总人口和GDP数据代替。
- 基础解析与评分测试已具备；采集接口的事务性、失败重试幂等和完整数据结构校验仍需补充，不能视为全计划验收完成。

## GitHub Secrets

- `INGEST_URL`：已发布 Sites 根地址
- `INGEST_TOKEN`：与 Sites 服务端密钥一致的长随机令牌
- `AMAP_KEY`：高德 Web 服务 Key，仅用于每周通勤与 POI 刷新

## 目标更新频率（未全部接通）

- 国家统计局 70 城与全国开发销售：月度
- 杭州透明售房网、南京网上房地产：每日尝试
- LPR：月度；货币政策报告：季度
- 土地、人口、供应与政策：月度/事件触发
- POI、地铁与通勤：每周

高德适配器使用 `Web服务` 类型 Key：项目与就业中心先地理编码，再按项目保存 3 公里内公园、地铁、商业、医院，以及三条就业走廊的公交/驾车时间。首次或手动运行强制刷新，之后按缓存采集时间满 7 天刷新；Key 仅从 `AMAP_KEY` Secret 读取。30001 引擎错误仅重试一次，鉴权错误不重试。错误记录不含密钥；失败保留最后一个通过定位校验的快照及原采集日期。

`basis_version` 保存统计基期断点；无法比较的序列不会直接拼接。项目只有在价格、110–140㎡户型、证照和三条通勤证据齐全时才进入推荐榜。评分不包含学区。
