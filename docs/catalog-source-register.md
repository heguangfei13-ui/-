# 目录扩充来源登记（2026-08-30）

本轮按购房类型“不限”扩充。目录身份、挂牌、成交和可评分证据分别处理；没有授权的逐套成交产品不接入。运行配置见 `data/catalog-sources.json` 的 `discovery`，所有新增来源均 `scoringEligible: false`。

## 杭州市物业管理协会市优项目公开查询

1. 名称：杭州市物业管理协会·市优项目公开查询。
2. 地址：https://hzswyglxh.com/SearchCityAuditList.aspx ，公开 HTML，不访问会员登录功能。
3. 官方性：行业协会第一方公开名录，**不是政府房管数据或房源供应平台**。
4. 更新时间：页面列有名录年度，不提供记录发布日期；`publishedAt` 留空，年度保存在来源备注和选录归档。
5. 推荐频率：30 天复核；缓存命中不改原采集时间。
6. 时间范围：本轮实际取得2021—2024年度72条住宅身份，不能作为当前物业服务质量判断；另1条含“?”的混合名称被隔离并记录，未擅自拆分。
7. 地理范围：杭州各区县，限本页实际收录；并非全市普查。
8. 字段：项目名称、区县、申报类型、名录年度。仅选择类型精确等于“住宅”的行；“非住宅”排除。“参评企业”是物业服务企业，不是开发商，不进入 developer。
9. 映射：名称/区县 → `ProjectSnapshot.name/district`；无门牌则显示“详细地址待核验”；类型设 `unknown`，仅标记 `catalogIdentity.verified`。价格、面积、总成本、评分均保持 null。
10. 可靠性：对名录身份和区县可归因；不能证明产权、二手可交易性、当前可售房源、学区或资产质量。
11. 缺失：小区完整覆盖、楼栋/分期关系、开发商、准确地址、价格与成交。营销名、备案名之间不做模糊合并。
12. 失败 fallback：保留原记录与原采集时间，来源质量标 stale；当天不重复请求失败源。
13. Freshness：`SourceMeta.collectedAt/basisVersion/quality/note`，以及目录 `health.lastAttemptAt/lastSuccessAt`；基准版本 `HZ-PROPERTY-IDENTITY-V1`。
14. 评分：不允许参与；历史市优记录不映射成物业或资产分数。

## 南京网上房地产住宅项目公开搜索

1. 名称：南京网上房地产·住宅项目公开目录。
2. 页面：https://www.njhouse.com.cn/project-list.html 。页面公开调用的只读搜索接口：https://www.njhouse.com.cn/jsmart/nj/web/webProjectSearch 。POST 表单为 `searchable.usage=住宅`、`page.pageNumber`、`page.pageSize=20`，不访问登录接口。
3. 官方性：南京市房地产市场交易中心公开平台，主管部门为南京市住房保障和房产局。
4. 更新时间：搜索响应没有出版时间；观察时刻单独保存，不以拟开盘时间代替出版时间。
5. 推荐频率：每日最多 3 页、每页 20 项；持久化页游标，随后按最旧销售观测轮转核验最多 40 个项目详情。
6. 时间范围：响应包含历史和近期项目；历史开盘日期不能推断当前在售类型。
7. 地理范围：南京各区的公开住宅搜索结果，分页尚未全量遍历，`complete` 始终 false。
8. 字段：项目编号、备案项目名、区县、项目地址、用途。删除电话、图片、挂牌/宣传价格等非必要字段。
9. 映射：编号 → `officialProjectNumber` 并复用已有项目 ID；名称/区县/地址 → 同名 Domain 字段。明确的“江北新区(浦口区)”或“江北新区(六合区)”映射为江北新区，并在归档及来源备注保留原区属，不推断其他模糊区属。新发现条目的 `housingType=unknown`，待类型证据；保留原来已核验的新房/二手分类。项目详情通过名称、住宅用途、计数平衡验证后，再写既有 `salesHistory/inventory`。
10. 可靠性：官方身份信息；地址可能只是地块四至，不能直接视作门牌或精确地图位置。
11. 缺失：当前挂牌供应、户型、住宅专用销售计数、逐套二手成交、均价。项目整体计数可能包含车位与商业。
12. 失败 fallback：保留已归档的有效页和旧项目；记录失败，不猜编号或遍历未公开接口。搜索页与请求分页不一致则拒绝。
13. Freshness：页面和选录原始字段存采集时间、原响应 SHA256；目录版本 `NJHOUSE-RESIDENTIAL-DIRECTORY-V1`。详情仍用 `NJHOUSE-ALL-USES-CUMULATIVE-V1`，两种口径不互换。
14. 评分：目录与累计销售不进入价格、二手流动性或最终评分。

## 南京网上房地产存量房住宅公开列表

1. 名称：南京网上房地产·存量房公开挂牌目录（仅小区身份）。
2. 地址：https://njzl.njhouse.com.cn/stock/houselist/t-1_p-1 ，分页按该页面公开 JS 使用的 `t-1_p-N` 路径；`t-1` 是住宅筛选。
3. 官方性：官方平台，但列表内容来自经纪机构挂牌；不是官方成交结果。
4. 更新时间：没有统一发布日期；以读取时间记录本次观察，不猜测上架日期。
5. 推荐频率：每日最多前 2 页；保留历史出现的小区身份，不把未再出现理解为售出。
6. 时间范围：采集当时可见的挂牌列表；不构造历史成交序列。
7. 地理范围：南京公开列表实际覆盖区县；排序偏差与前页抽样明确保留，非全量存量小区目录。
8. 字段：只提取小区名称和区县。先验证页面确实选中“住宅”及对应页码；不保存个人姓名、联系方式、经纪人、逐套房源 ID、挂牌价格或具体房号。
9. 映射：名称/区县 → `ProjectSnapshot` 身份，`housingType=resale`；不将单套挂牌面积/价格填入小区面积范围、均价、总成本或 `salesHistory`。
10. 可靠性：可证实该名称在官方平台的经纪挂牌住宅列表中出现；不代表已交叉验证产权、实际可交易性或交易真实性。
11. 缺失：官方小区 ID、备案名/营销名映射、完整房源数、成交记录、经纪人去重。只做同城市+同区县+精确同名去重；分期、跨区同名保留。
12. 失败 fallback：保留旧身份与原观察时间，来源标 stale；不将登录、访问限制或空页作为成功空数据覆盖。
13. Freshness：每页选录归档保存 URL、原响应 SHA256、采集时间；`NJHOUSE-STOCK-IDENTITY-V1`。不归档含个人资料的完整 HTML。
14. 评分：不允许参与；不产生二手成交记录或价格评分。

## Schema Requirement（交 Architecture + API & Persistence）

当前 `ProjectSnapshot` 只能表示小区/项目汇总，尚不能准确承载挂牌房源。若下一步接入单套挂牌或获授权成交，应先定义独立 listing/transaction 契约，明确：报价/成交价类型、单位、套型面积、观察/上架/成交日期、独立来源、许可范围、与小区的匹配证据及冲突状态。物业企业也需独立字段，不能占用 `developer`。本轮没有增加核心 Domain 类型、D1 字段或迁移。

## 发布边界

本地采集只更新快照、原始选录归档和文档，不调用 ingest，不写生产 D1，不自动发布。既有定时任务下次使用更新后的采集代码时，仍走原有 ingest；代码与本地数据进入部署需单独批准。
